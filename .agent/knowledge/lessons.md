# Lessons — 经过验证的可复用经验

> 经过真实失败 / 成功验证、且未来 Agent 应该知道的内容。

**使用方式：**

- 在开始非平凡工作之前读它，类似于读 workflow。
- 当你解决了一个非显而易见的问题，按下面格式**追加**一条（并遵循 `AGENTS.md` 的晋升规则）。
- 条目保持简短。需要三页纸才能讲完的"经验"，通常应该放进 `pitfalls` 或 `decisions`。

**条目格式：**

```markdown
## Lesson: 标题

### 背景

### Root Cause / 关键发现

### 解决方案

### 可复用原则

### 相关文件
```
